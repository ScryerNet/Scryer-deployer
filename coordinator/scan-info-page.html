Internet measurement research

This host is part of an academic / security research project that performs low-rate, non-intrusive network measurements across the public internet. We record which ports respond and collect publicly presented banners, TLS certificates, SSH host keys, and DNS records. We do not attempt to log in, exploit, or access any private data.

What we collect

  • Open TCP ports (SYN scan)
  • Service banners and HTTP response headers
  • TLS certificates and JARM server fingerprints
  • SSH host-key fingerprints and supported algorithms
  • Reverse DNS (PTR) records
